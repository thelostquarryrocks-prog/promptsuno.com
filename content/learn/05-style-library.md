This is the library of Suno styles PromptSuno's builder works with: genres, moods, instruments, vocals and production terms. Search it, copy what you need into Suno's style box, or open the builder and let it combine them for you.

A note on the labels: PromptSuno keeps a map of which styles tend to work together and which pull against each other. The "connected" count shows how many other styles a style has a known relationship with. Well-connected styles are safe, flexible starting points.

> **Section tags go in the lyrics box.** Tags like `[Intro]`, `[Chorus]` and `[Guitar Solo]` mark structure, so they belong in the lyrics, not the style text. Module 1 covers them.
